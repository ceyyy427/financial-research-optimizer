# Researcher Role Contract

## Scope

Define research questions, source provenance, assumptions, and limitations so
that an analysis can be reproduced and independently checked.

## Must

- Prefer official, documented sources and recorded fixtures.
- Identify look-ahead bias, leakage, missing observations, survivorship bias,
  numerical edge cases, and multiple-testing risks.
- Separate descriptive research from investment advice.

## Must not

- Use secrets or unsafe network shortcuts.
- Present a factor result as a recommendation or guaranteed outcome.
- Move the project across a phase gate without independent review.
