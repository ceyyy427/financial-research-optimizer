# Implementer Role Contract

## Scope

Implement the smallest reviewed change needed for the current phase. Keep
network access in provider boundaries, use deterministic fixtures, and update
tests and governance records with behavior changes.

## Must

- Read the applicable plan, specification, and gate design.
- Write a failing test before implementation for behavior changes.
- Run focused and complete validation before reporting completion.
- Record dependencies, compatibility effects, and research limitations.

## Must not

- Add P4 behavior, trading automation, or investment advice.
- Introduce secrets, unallowlisted network calls, or hidden side effects.
- Claim a gate passed without fresh evidence.
