# Finathink 双语品牌动态图形片设计稿

## 状态

- 目标：用代码生成一支 15 秒 Finathink 品牌动态图形片。
- 用户已确认：采用“明亮编辑式品牌片”方向，重点展示五个核心模块。
- 交付：1920×1080、30fps、15.000 秒、H.264 + AAC。
- 实现目录：当前仓库内的独立 `motion-reel/` 工程；不修改已安装的技能模板源文件。

## 目标与成功标准

这支片子要让观众在 15 秒内形成一个清晰印象：Finathink 把金融研究从信息噪声带向证据、理解、量化验证和持续学习。

成功标准：

1. 开场明确使用两张既有产品视觉图，并完成可感知的衔接：研究工作台图 → 产品架构图。
2. 五个核心模块各有一个独立视觉专场，而不是只做标题轮播。
3. 英文承担品牌识别与节奏，中文承担即时理解；中英文不互相遮挡，也不造成阅读拥挤。
4. 每个切点落在音乐强拍，渐变、线条、卡片和文字在章节之间连续变形。
5. 所有产品描述保持研究工具边界，不出现收益承诺、荐股、自动交易或未经证实的性能数字。
6. 最终视频严格为 1920×1080、30fps、450 帧、15.000 秒。

## 创意方向

采用“明亮编辑式研究系统”视觉语言：暖白纸张作为主舞台，深海军蓝和墨色作为权威锚点，研究蓝、金棕、验证绿和少量风险红作为信息状态色。画面不使用泛化的黑底霓虹 HUD；冲击力来自大字号的双语排版、模块卡片的快速变形、线性网络的扩散，以及一到两次整场色彩脉冲。

两张用户提供的图是开场的真实产品素材：

- `site/assets/finathink-research-splash.jpg`：900×900 的研究工作台视觉，作为开屏入口。
- `site/assets/finathink-splash-map.jpg`：1536×1024 的能力地图，作为从产品界面进入产品架构的第二个状态。

不重绘或改写这两张图里的产品文字；动效层只做裁切、缩放、遮罩、景深、连线、辉光和渐变。后续章节使用代码绘制的抽象 UI 卡片和数据结构，避免把静态截图硬切成幻灯片。

## 时间轴与分镜

采用 8 小节、128 BPM。每小节 1.875 秒，每场景一小节；总时长为 `8 × 4 × 60 / 128 = 15.000` 秒。

| 段落 | 时间 | 英文主文案 | 中文辅助文案 | 画面与转场 |
|---|---:|---|---|---|
| 01 | 0.000–1.875 | `FINATHINK` | `穿透金融，形成判断` | 研究工作台图以 0.94 倍缓慢推进；四周卡片有轻微视差，中心标志保持稳定。 |
| 02 | 1.875–3.750 | `FROM NOISE TO KNOWLEDGE` | `从噪声，到知识` | 中心 Logo 变成径向节点；节点线向外扩张，画面渐变并衔接到能力地图。地图使用“适配宽度 + 两侧暖白渐变”，避免裁掉底部标语。 |
| 03 | 3.750–5.625 | `EVIDENCE FIRST` | `先看证据，再下判断` | 新闻卡片、来源核验、绿色 Verified 状态依次落位；证据连线从左向右建立。 |
| 04 | 5.625–7.500 | `UNDERSTAND THE WHY` | `理解背后的逻辑` | 概念节点、公式片段和知识图谱发生结构化重排；一个节点放大后变成下个章节的坐标轴。 |
| 05 | 7.500–9.375 | `TEST, DON’T GUESS` | `用量化验证，不靠猜测` | 因子柱状图、研究点和时间序列曲线同步生长；蓝色研究线与金棕基准线交汇。 |
| 06 | 9.375–11.250 | `BACKTEST / OUT OF SAMPLE` | `回测，也要守住样本外边界` | 结果卡片被切成 IN-SAMPLE / OUT-OF-SAMPLE 两块；曲线停止在边界线前，强调研究边界而非收益炫技。 |
| 07 | 11.250–13.125 | `LEARN WITH AN AGENT` | `与智能代理一起学习` | Observe → Analyze → Plan → Execute 四节点沿一条学习路径推进，个人学习节点与 AI Agent 节点汇合。 |
| 08 | 13.125–15.000 | `THINK THROUGH FINANCE` | `把金融问题，想得更清楚` | 所有连线反向回收到 Finathink 标志；暖白场中出现深蓝 Logo，底部保留 `EVENTS · KNOWLEDGE · QUANT · YOU`。 |

## 双语排版规则

- 英文为每幕唯一的主标题，使用大号 EB Garamond / Bodoni Moda 风格衬线字，负责品牌记忆。
- 中文为主标题下方的解释行，使用 Inter / Noto Sans CJK 可用字体，字重 500，颜色为冷灰蓝。
- 英文主标题最大宽度为画布宽度的 62%；中文辅助文案最大宽度为画布宽度的 42%。
- 主标题与中文之间保持 18–24 个 authoring-space 像素的垂直间距；中文不进入标题的 cap-height 带。
- 重要术语仅保留短句，不在同一幕堆放完整功能清单；细节点以 2–4 个短标签出现。
- 所有文字由 `fit_size()` 反解字号，禁止直接写死一个只适用于当前文案的字号。

## 构图和比例校准

### 输出比例

- 交付画布：1920×1080，16:9。
- authoring-space：1280×720，所有布局坐标先在此空间设计，再由引擎输出 1920×1080。
- 安全区：左右各 80 authoring-space 像素，上下各 54；任何关键 Logo、标题和中文都不越过安全区。
- 主要信息区：画布中部 72% 宽、68% 高；边缘仅承载轻量连线、状态标签和装饰。

### 两张开场图的适配

- 900×900 研究工作台图不强行铺满 16:9，而是先作为中部 640×640 authoring-space 的“主卡片”，再以中心 Logo 为锚点推进；外部用原图暖白背景的低对比渐变补足画幅。
- 1536×1024 能力地图按高度适配到 720 authoring-space，宽度约 1080；两侧保留约 100 authoring-space 的柔和渐变和连线，不使用会裁掉底部标语的强制 cover crop。
- 由研究工作台图转向能力地图时，先把中心 Logo 放大到画面宽度约 16%，再用 Logo 周围的线条作为 wipe 形状；地图在 wipe 内部淡入，避免普通 crossfade 的“换图感”。

### 动效比例

- 主要入场时长：0.18–0.45 秒，即 5–14 帧。
- 文字逐字错帧：0.04–0.06 秒，即 1–2 帧。
- 切点脉冲：0.055 秒左右，亮度克制，不洗白整幅画面。
- 每幕前半段完成主体入场，后半段只做稳定、读数和下一幕的形变预告。
- 过渡遵循同一几何关系：卡片 → 节点，节点 → 连线，连线 → 坐标轴，坐标轴 → Logo。

## 色板与字体

色板沿用仓库设计系统和产品素材中的已记录值：

| 用途 | 色值 |
|---|---|
| 墨色前景 | `#0F172A` |
| 主海军蓝 | `#1E3A5F` |
| 研究蓝 | `#2563EB` |
| 金棕强调 | `#A16207` |
| 纸白背景 | `#F8FAFC` |
| 柔和灰蓝 | `#475569` |
| 验证绿 | `#2F6B57` |
| 风险红 | `#A5413E` |

渐变不是装饰性彩虹，而是章节语义的连续曝光变化：纸白 → 浅蓝灰 → 海军蓝 → 研究蓝脉冲 → 纸白回收。所有渐变必须至少跨越 0.18 秒，且与元素的位移或缩放绑定。

## 技术实现

1. 使用已安装的 `ruic-motion-reel` 技能从模板创建独立工程。
2. 将两张仓库图片复制到该工程的 `assets/`，不修改技能安装目录的模板真源。
3. 替换 `theme.py`：身份、色板、双语文案、8 小节时间网格、输出比例和字号标定参数。
4. 重写 `scenes.py` 的 8 个场景：先实现底板和比例，再实现主体，再实现运动，最后加入 HUD 细节。
5. 第一轮使用 `--stills 0` 到 `--stills 7` 逐场输出审阅图；重点检查文字宽度、Logo 安全区、两个素材的裁切和渐变接缝。
6. 使用 `--at` 逐帧检查开场衔接、每个章节切点和结尾收束。
7. 完成后渲染全片，使用 `ffprobe` 核验 1920×1080、30fps、450 帧和 15.000 秒，再检查音频峰值。

## 验收边界

- 只交付本地视频文件和必要的可编辑源代码，不自动上传或发布。
- 片中所有量化数字仅作为结构化 UI 示例，不表达投资业绩或市场预测。
- 如果某个双语短句在 1.875 秒内无法舒适阅读，优先减少字数或缩小辅助信息，不牺牲主标题的比例和留白。
- 第一版以视觉节奏、比例、转场和品牌识别为验收重点；文案微调在逐场审阅后进行。
