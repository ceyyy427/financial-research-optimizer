# P7 Evidence-Linked Community

The smallest evidence-linked community slice is: create a room, join it,
author a labeled post, publish a consented projection, attach that projection,
and read it as an active member. A second user cannot attach evidence to a
post they do not author, and a room member cannot read another user's private
node.

The product renders claim label, projection version, source fingerprint (or a
human-safe short identifier), limitations, and revocation/stale status. It
never renders private fields or hidden prompts. A comment can quote a public
projection but cannot mutate its source. Saving a post creates a private
question node owned by the saver.

The slice is deliberately narrow: no ranking, reputation, recommendation
marketplace, autonomous moderation, broker, or live trading integration.
