# P7.5 user journeys

## Event understanding

1. HOME opens the captured CPI fixture and shows `CAPTURED`/`SAMPLE` state.
2. EVENTS shows the chain CPI → inflation → rates → bonds → discount →
   valuation, with evidence identifiers and limitations.
3. The user opens a linked KNOWLEDGE concept and can inspect intuition, formal
   definition, equation, derivation, code example, and finance/quant/strategy
   applications.

## Quant experiment

1. The user states a question about a rolling feature.
2. A deterministic experiment records the hypothesis, fixture status, result,
   and evidence reference. No forecast is presented.

## Strategy research

The same StrategySpec is reviewed through idea → spec → features → backtest →
out-of-sample → paper → compare → learn → export. Guided and advanced views
are presentations of that contract; they are not separate strategy engines.

## Personal continuity

Save creates a private P7 node. A file-backed SQLite configuration survives
process restart, and `/api/reopen` returns the same export. Ownership and
authorization remain in the repository.

## Community projection

Community is a calm evidence room: claims, research references, questions, and
counter-evidence may be projected only through explicit P7 consent. There are
no public personal graphs, leaderboards, or automatic publishing actions.
