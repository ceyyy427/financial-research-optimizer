# P7.5 Execution Plan

## Scope

P7.5 turns the validated P4–P7 research core into a local-first learning
product. It is additive: P6.5 remains the event/evidence authority, P6.6 the
strategy/research authority, and P7 the private graph, consent, projection,
and deletion authority.

## Delivery sequence

1. **Knowledge contract** — typed concepts, prerequisite graph, equations,
   derivations, code, financial/quant/strategy links, misconceptions, source
   references, and deterministic learning paths.
2. **Local shell** — loopback HTTP service, SQLite default, captured BLS/sample
   mode, accessible product worlds, diagnostics, and safe errors.
3. **Journey validation** — event, knowledge, quant, strategy, save/reopen,
   and evidence-linked community journeys.
4. **P7.5 gate** — full suite, both Python environments, Ruff, notebook,
   governance, pip, migration, build, diff, clean worktree, provenance, and
   the independent A–J reviews.
5. **P8 handoff** — source-install public beta documentation and release
   workflow; no cloud, broker, or real-money expansion.

## Exit criteria

The phase exits only when the 39-item matrix in the final validation report is
evidenced. A conditional item (for example Apple signing or an external
GitHub release) is never represented as a pass; the report names the missing
external prerequisite and keeps the supported source-install path usable.
