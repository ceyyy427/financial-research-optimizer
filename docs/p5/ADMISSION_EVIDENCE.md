# P5 Open-Source Admission Evidence

**Review date:** 2026-10-02 (Asia/Shanghai)

This page records the official upstream entry points used for the P5 admission
review. Each candidate was checked as a repository/README/license/release,
issue/maintenance, and security surface. A security tab or an empty advisory
surface is not treated as a guarantee of safety; it is a prompt for the next
review before installation. Compatibility and dependency conclusions are in
`COMPONENT_ADMISSION_MATRIX.md`.

The full six-step admission (including an isolated benchmark and decision) was
completed only for the admitted statsmodels adapter. Rows marked optional,
reference, or rejected are deliberately non-admission screens: no package was
installed and no benchmark was run for them, so they cannot enter the runtime
without a new review.

## Installation evidence

Only statsmodels passed the P5 sandbox admission and smoke test. Its concrete
version, arm64 wheel, dependency tree, `pip check`, and adapter result are in
`OPTIONAL_SANDBOX.md`. The other rows remain candidates or references and were
not installed, imported by core code, or added to the project manifest.
