# finathink.cloud entry surface

This is the content contract for the lightweight marketing/documentation
surface. The hosted page should remain a clear entry point to the local app,
source repository, documentation, and the canonical GitHub Releases page.

## Navigation

`HOME` · `WHY FINATHINK` · `FEATURES` · `KNOWLEDGE` · `QUANT` · `STRATEGY LAB`
· `OPEN SOURCE` · `DOWNLOAD` · `DOCS` · `GITHUB`

## Message and calls to action

> Understand finance by thinking with data.

Use `DOWNLOAD FINATHINK`, `VIEW ON GITHUB`, and `READ DOCUMENTATION` as the
primary calls to action. Explain the loop as real events → evidence →
understanding → mathematics → code → reproducible research → learning.

Do not promise alpha, beat-the-market outcomes, AI stock predictions, or
real-money execution. Explain that the beta is local-first, source-backed,
research-only, and keeps the user as the final thinker.

## Release linking rule

The `DOWNLOAD` and `GITHUB` buttons must resolve to the repository's real
GitHub page and published release assets. Until a maintainer publishes a
release, links remain configuration placeholders and must not invent a version
or checksum. See [P8_PUBLIC_BETA_GATE.md](p8/P8_PUBLIC_BETA_GATE.md).
